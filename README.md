# Halal Analyzer

A small SwiftUI ingredient-screening app by Saleh Alayed for iPhone and iPad. Paste ingredient text to review locally matched ingredients and additives. Ambiguous items are marked for further review.

The app uses local keyword rules, not a trained AI model or a remote service. It is an informational prototype, not halal certification or a substitute for checking ingredient provenance with a qualified certifier.

## Build

Open the included Xcode project on macOS. Select your own development team and signing settings for device installation. Source and project assets are included; personal Xcode state and local notes are excluded. This is a source publication, not a newly tested or App Store release.
