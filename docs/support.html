HalalTag support

HalalTag checks a small, supported set of English ingredient terms in text you type or paste.

Updated: 17 November 2026. These instructions describe the ad-free text-screening feature in version 1.0.

Check ingredient text

  1. Type or paste the English ingredient text you want to review.
  2. Choose Screen text.
  3. Read the result and any explanation of supported matching terms.
  4. Check the original label. Ask the manufacturer or a qualified certifier when ingredient source or certification is unclear.

You can also try the included sample texts. Editing the text clears the previous result so you can screen the revised text again.

Remove the current text and result

Choose Clear to remove the text and result currently shown. This version does not provide a saved scan history or favorites list.

Understand an unknown result

The screening covers only a small explicit list of English terms. An unrecognized word or language can be missed. If no supported term is found, the result remains unknown.

HalalTag does not determine halal status. Word matches cannot verify ingredient presence, origin, processing, contamination or certification.

Camera and barcode questions

This version accepts typed or pasted text. It does not scan photos or barcodes and does not use a camera.

Ask a question or report a problem

Use the existing HalalTag public issue channel for non-sensitive questions, bug reports or suggestions. GitHub requires you to sign in to post. You can also read existing requests.

This is a public channel. Your GitHub username, request and any attachments can be read by other people. Do not post private contact details, credentials, personal documents or sensitive information. Use a non-sensitive example instead of a personal ingredient list or screenshot.

  1. Give the issue a short title that describes the problem.
  2. Include the app version, device model and iOS or iPadOS version.
  3. Describe the steps you took, what happened and what you expected. Include only the minimum non-sensitive example needed to explain the issue.

This channel does not offer a guaranteed response time. It is not a private messaging service and cannot verify a product’s ingredient sourcing or halal certification.
