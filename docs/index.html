HalalTag privacy and limitations

Developer: Saleh Alayed

Updated: 17 November 2026

This notice describes HalalTag’s ad-free English ingredient-text screening feature in version 1.0, and the separate webpages and public support channel linked below.

What this version does

HalalTag checks a small set of English ingredient terms in text you choose to type or paste. Screening runs on your device. This version does not use a camera, OCR, barcode scanning or a remote ingredient-analysis service.

Your ingredient text and results

The screening screen keeps the current text and result in memory on your device. It does not send them to the developer or a remote screening service, and it does not save a scan history or favorites list. The app does not create a user account or include advertising or analytics SDKs.

Clear removes the current text and result from the screen. Editing the text clears the previous result so you can screen the revised text again.

The screening feature does not request camera, photo library, microphone or location permissions.

Your device and keyboard

Keyboard, dictation, clipboard and other iOS services remain subject to your device settings and their providers’ practices. This description of HalalTag’s screening feature does not make guarantees about those separate services or about the security of your device.

Visiting these webpages

When you visit these pages on GitHub Pages, your browser sends a request to GitHub. GitHub states that it logs and stores visitors’ IP addresses for security purposes, including when visitors are not signed in. This is separate from the app’s on-device ingredient screening. These pages contain no advertising, analytics script or contact form.

Read GitHub Pages data collection information and the GitHub Privacy Statement.

Public support requests

You can ask a non-sensitive app or privacy question through the HalalTag public issue channel. Posting requires a GitHub account. Your GitHub username, issue text and any attachments you choose to submit are handled by GitHub and are visible to the repository maintainer and other people on the internet.

Support requests are public. Do not include private contact details, account credentials, personal documents or sensitive ingredient examples. Use a short, non-sensitive example when reporting a screening problem.

Issue content may remain in the public repository and may be copied by others. You can use GitHub’s available editing and privacy controls. For a question about a post, refer to its issue number without repeating private information. GitHub’s privacy statement explains its own data handling and privacy-request options. No response time, removal or confidentiality guarantee is made for this public channel.

What results mean

A match identifies supported words in the supplied text. It does not establish ingredient presence, source, processing, contamination or halal certification. Unrecognized terms and languages may be missed.

No supported match means the status is unknown. It does not mean that a product is certified. Check the original label and seek source or certification information when needed.

Questions about this notice

Read the support instructions before opening a public request. Questions about GitHub’s handling of your account or website data should use the privacy options in the GitHub Privacy Statement.
