HalalTag privacy and limitations

Developer: Saleh Alayed

What this version does

HalalTag checks a small set of English ingredient terms in text you choose to type or paste. Screening runs on your device. This version does not use a camera, OCR, barcode scanning or a remote ingredient-analysis service.

Your ingredient text and results

The screening screen keeps the current text and result in memory. This feature does not save a scan history or a favorites list and does not send ingredient text to a remote screening service.

Clear removes the current text and result from the screen. Editing the text clears the previous result so you can screen the revised text again.

Your device and keyboard

Keyboard, dictation, clipboard and other iOS services remain subject to your device settings and their providers’ practices. This description of HalalTag’s screening feature does not make guarantees about those separate services or about the security of your device.

Visiting these webpages

The planned hosting provider for these privacy and support webpages is GitHub Pages. Visiting the published pages will send a web request to GitHub. GitHub states that it logs and stores visitors’ IP addresses for security purposes, including when visitors are not signed in. This website hosting is separate from the app’s on-device ingredient screening.

Read GitHub Pages data collection information and the GitHub Privacy Statement.

What results mean

A match identifies supported words in the supplied text. It does not establish ingredient presence, source, processing, contamination or halal certification. Unrecognized terms and languages may be missed.

No supported match means the status is unknown. It does not mean that a product is certified. Check the original label and seek source or certification information when needed.
